價格分布曲線（常態分布 SVG）
用 JS 計算常態分布曲線座標，畫出鐘形曲線。橙色虛線是均價，藍色實心圓是最新採購位置，讓用戶直覺判斷現在買貴還是買便宜。
純 SVG 常態分布公式 101 個座標點
PREVIEW（靜態示意）
低← 價格分布 →高 
/* 常態分布公式 */
const norm = x =>
  Math.exp(-0.5 * ((x - avg) / std) ** 2);

/* 101 個點畫出平滑曲線 */
const pts = Array.from({length: 101}, (_, i) => {
  const x = xMin + i/100 * (xMax - xMin);
  return [xCoord(x), yCoord(norm(x))];
});
